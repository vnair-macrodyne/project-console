Project Plan — Budget, Schedule & Progress

One place to manage a project on the console: bring it in (or remove it), see its budget & efficacy, and enter this week's schedule & progress. Saving records progress against the current week; the dashboard reads the latest week.

Progress — Machine × Discipline

Enter the hours remaining to completion for each machine × discipline cell, with its budget and actual hours shown. % complete (= actual ÷ (actual + remaining)), earned hours and CPI update live. The greyed number is the budget-implied remaining (budget − actual) as a starting point. This is the one judgement the plan needs: the per-discipline % the dashboard run-out uses is rolled up from these cells — no separate entry. A machine worked but never budgeted is flagged so the plan can be corrected.

Run-out overrides — optional

Leave blank to use the calculated run-out. Enter a value only to override it (e.g. a known scope change the math can't see yet); the dashboard flags it as “manual”. Material run-out is otherwise computed from committed POs, floored at budget.
